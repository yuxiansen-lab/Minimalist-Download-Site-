# Minimalist-Download-Site-
简介：这是一个简陋的下载站，采用[mdui](https://mdui.org)和php搭建。

**设定在config.php里更改！！可以改默认的后台密码，网站标题
counts.json是数下载次数的，哈希值加密
admin.php里更改cloudflare的人机验证配置（site-key和secret-key）
notice.txt是公告**

！！！文件都存储在file里，可以再后台设置加密文件夹或直接在文件夹里创立一个.password文件，内容为自己的密码即可。
直接全拷贝到本地就安装完了。
可能还会有些小bug
